# بوت "وأذّن في الناس"

بوت تيليغرام ينشر رسائل إسلامية تلقائيًا في قنوات محددة حسب مواعيد يضبطها مالك كل قناة.

## البنية

```
index.js                  نقطة الدخول: Express + Webhook + بدء التشغيل
src/db/                   كل التعامل مع Supabase (channels, progress, schedules, messages)
src/bot/                  منطق البوت (الأزرار، الأوامر، الرسائل النصية)
src/scheduler/            محرك الجدولة (node-cron، بتوقيت Asia/Riyadh)
src/utils/time.js         تحويل الوقت العربي (8:30م) ↔ صيغة 24 ساعة
migration.sql             سكريبت إنشاء الجداول في Supabase
test/                     اختبارات وظيفية بمحاكاة كاملة لـ Supabase (بدون شبكة حقيقية)
```

## الإعداد

1. انسخ `.env.example` إلى `.env` واملأ القيم (أو اضبطها كمتغيرات بيئة على Render).
2. نفّذ محتوى `migration.sql` في Supabase SQL Editor (لن يمسّ جدول `messages`).
3. `npm install`
4. `npm start`

## التشغيل على Render

- Build Command: `npm install`
- Start Command: `npm start`
- تأكد من ضبط جميع متغيرات البيئة في `.env.example` في لوحة Render.
- أبقِ UptimeRobot (أو ما شابه) يستدعي رابط الجذر `/` بشكل دوري لمنع نوم الخدمة، لأن المواعيد الفائتة لا تُعوَّض.

## الاختبارات

```
npm test
```

يشغّل مجموعة اختبارات وظيفية (`test/manualTest.js`) تحاكي Supabase بالكامل في الذاكرة
(`test/mockSupabase.js`) للتحقق من:
- منطق ملكية القنوات بحالاته الأربع
- الحد الأقصى للمواعيد (24) ومنع تكرار نفس الوقت
- منع تنفيذ نفس الموعد مرتين في نفس اليوم (`claimSchedule`)
- تجاهل القنوات المعطّلة عند البحث عن المواعيد المستحقة
- تسلسل نشر الرسائل بدون تكرار أو قفز أو Looping عند نفاد الرسائل
- تعطيل القناة تلقائيًا عند فقدان صلاحية النشر

هذه الاختبارات لا تحتاج اتصالاً حقيقيًا بـ Supabase أو Telegram.
